usq-backup

A personal backup tool.

usq-backup copies a database and its source files from the owner's own server to the owner's own Google Drive once a week. It uses the Google Drive API with the drive.file scope only, so it can see and manage only the backup files it created itself. It does not read, list, change or share any other file in the Drive.

The tool is used only by its developer for their own data. It is not offered to other users.
