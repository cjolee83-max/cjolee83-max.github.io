usq-backup Privacy Policy

Last updated: 2026-09-19

What the app accesses

usq-backup requests only the Google Drive drive.file scope. With it, the app can create, read, update and delete only the files and folders it created itself (weekly backup archives). It cannot see any other file in the user's Drive.

How the data is used

The app uploads backup archives of the owner's own server data to the owner's own Google Drive, checks them after upload, and moves backups older than four weeks to the Drive trash. Nothing else is done with Google user data.

Sharing, storage and retention

No Google user data is sold, shared with third parties, or sent anywhere other than the owner's Google Drive. The access token is stored only on the owner's private server, readable only by the owner's account. Access can be removed at any time at myaccount.google.com/permissions.

Who uses it

The app is used only by its developer for their own data.

Limited Use

usq-backup's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
